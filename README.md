# UnityBlueSapp

Unity 6000.6.8f1向け、80年代PC風の一人称探索＋リズム戦闘プロトタイプ。

## 起動
Unity Hubでこのフォルダを開き、`Assets/BlueSapp.unity`を開いてPlay。
Windows実行版は`BlueSapp > Build Windows Player`から作成する。出力先は`Build/BlueSapp.exe`。

## 操作
- メニュー: ↑↓、Enter。はじめから→導入→街。
- 探索: ↑前進、↓後退、←→90度旋回、Enterで扉・部品を調べる。
- M: 全画面半透明マップ。探索中のみ表示し、戦闘後に復帰。
- 戦闘: 右パネルの3レーンを落ちるノーツが下の判定線に重なる時にF（盾）・Space（回避）・J（銃）。
- 遭遇時はReturnで開始。初回は説明を表示し、3・2・1のカウント後にBGMと譜面を開始する。
- HP0: やられBGMと敗北表示、Enterで街へ帰還し全回復。
- 街: ダンジョンへ入る／セーブ。保存先はUnityのpersistentDataPath内`bluesapp.json`。

## 内容
固定2人編成、入口の初回チュートリアル、固定配置の壊れた多脚ロボ2体、外装回収、正常な多脚ロボのボス、第一層クリアを実装。
外装は(3,5)、ボスは(11,9)。町から入って最初のマスのEnterで帰還できる。
相棒はフレーム／外装の図形仮CG。正式素材に交換する場所は`BlueSappGame.DrawAndroid`。
探索／街、戦闘、敗北で生成矩形波の仮BGMが切り替わる。画像や曲の外部素材は使用していない。

## 試作数値
判定幅±0.20秒。ノーツ間隔0.75秒（80BPM）。通常予告2秒、外装装着後3秒。HP40開始。
外装は防御ミス被害を3軽減、盾成功時の被害を1から0にする。レベルアップは最大HP+8、攻撃+2。
キーを連打しても誤キーは判定されない。厳密な連打ペナルティや難易度調整は今後の対象。
現時点のセーブ対象は主人公の成長・外装・撃破フラグ。地図の探索記録と扉の開閉状態は起動中のみ保持する。
音・絵・譜面は初期動作確認用。最終アートや完成版バランスではない。

## 単体試験
Unityをbatchmodeで起動し`-executeMethod BlueSappTests.Run`を指定する。
成功時にログへ`BLUESAPP TESTS PASSED`を出力。移動、扉、判定幅、各キー、外装、防御被害、敗北、全回復、レベル、セーブ往復、マップ到達性を検証。
実行版の`-bluesapp-smoke`は探索／戦闘状態へ切り替えて終了する診断用モード。非表示ウィンドウではPNGが黒くなるため、画像による見た目の合格判定には使わない。
