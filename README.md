# UnityBlueSapp

80年代PC風の一人称ダンジョン探索とリズム戦闘を組み合わせる、小規模なUnityサンプルゲーム。

主人公＋アンドロイドの固定2人編成で探索し、回収した部品で相棒を強化します。左側に探索／戦闘画面、右側の約1/3にアンドロイドの全身CGを表示する構成です。

## 仕様

[ゲーム仕様書](SPEC.md)に、決定事項と未確定事項をまとめています。

## 開発環境

- Unity `6000.6.8f1`
- 想定初期ビルド: Windows

Unity Hubでこのフォルダをプロジェクトとして追加して開きます。現時点では仕様書と雛形のみで、ゲーム本体は未実装です。

雛形のエディタメニュー:

- `BlueSapp > Create Start Scene`: 空の開始シーンと基本プレイヤー設定を作成。
- `BlueSapp > Build Windows Player`: Windows用ビルドを`Build/`に出力（ゲーム本体の実装前です）。

アンドロイドの正式CGはユーザー制作予定です。開発中は仮素材を使用します。
